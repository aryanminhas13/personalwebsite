01 / KEEPING WORK MOVING

A hundred thousand jobs.
One moving system.

What happens when a worker fails halfway through a job? I built a distributed job orchestration platform to handle the messy parts: scheduling, retries, cancellation, and recovery.

A Go API and persistent queues coordinate the work. A React dashboard brings status, logs, and metrics into view in real time through WebSockets.

02 / PLAY IT. MEASURE IT.

A game with a
story in the data.

Packet Panic started with the things that make an arcade game tick: collision detection, rising difficulty, and controls that work on a keyboard or a touchscreen.

I also wanted to see what happens between the first move and game over. I instrumented gameplay events, then built an interactive analytics dashboard to explore wave progression, survival duration, and interception rates.

WORK WITH REAL IMPACT

Finding value in the data.

Less friction. More progress.
